Hệ thống OCR đa miền tự động nhận dạng và định tuyến 3 loại: Biển số xe (LP), Container hông (Side), Container nóc (Aerial).

[1] QUY TẮC ĐỊNH TUYẾN PREFIX
  • Tên ảnh chứa prefix lp / bienso: Chạy pipeline Biển số.
  • Tên ảnh chứa prefix noc / aerial / top / camnoc: Chạy pipeline Container Nóc.
  • Các trường hợp còn lại: Chạy mặc định Container Hông.
[2] XỬ LÝ FILE ZIP

Hỗ trợ nén nhiều ảnh dạng tệp .zip. Tệp zip sẽ được giải nén trực tiếp trong bộ nhớ RAM (không ghi đĩa cứng) để tăng tốc độ xử lý hàng loạt.

[3] CẤU HÌNH TỰ ĐỘNG QUA PREFIX.MD / PREFIX.TXT

Để tự động nạp từ khóa định tuyến khi tải tệp ZIP, đặt file prefix.md hoặc prefix.txt ở thư mục gốc của tệp ZIP với định dạng mẫu sau: 

# Dấu thăng dùng để viết chú thích
lp = lp, bienso, custom_lp
top = noc, aerial, camnoc, top
[4] CẤU HÌNH SIDEBAR

Người dùng tùy chỉnh từ khóa prefix động và ngưỡng độ tin cậy (`DET CONF`), số lượt biểu quyết TTA (`TTA VOTES`) tại bảng điều khiển bên phải.
